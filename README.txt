AZIZSAAD.COM — PERSONAL HOMEPAGE
================================

A clean, bilingual, responsive personal website for Abdulaziz Saad.

CONTENTS
  index.html     Website content and structure
  styles.css     Visual design and mobile layout
  script.js      English/Arabic switch, copy-email functionality
  portrait.jpg   TEMPORARY initial-based placeholder image
  favicon.svg    Browser tab icon

TO ADD YOUR PHOTO
  Replace the included portrait.jpg with your own photo using the
  SAME filename: portrait.jpg. A vertical, head-and-shoulders photo
  works best; ideally at least 1200 x 1500 pixels. The site will crop
  it automatically to fit the portrait frame.

TO PUT THE SITE ONLINE
  Upload index.html, styles.css, script.js, portrait.jpg, and favicon.svg
  to your website hosting provider's public website folder.
  Configure your domain (azizsaad.com) to point to that hosting.
  Enable HTTPS/SSL. The website can be hosted as a static site.

EMAIL
  The page displays a@azizsaad.com and has a mailto link which opens
  the visitor's email app. It does NOT host email or create a mailbox.
  You must set up a@azizsaad.com with an email provider separately,
  and configure the domain's MX, SPF, DKIM and DMARC records.

LANGUAGE
  English is the default; the language button switches to Arabic,
  including right-to-left layout. The Arabic link is:
  https://azizsaad.com/?lang=ar

PRIVACY AND DEPENDENCIES
  No contact form, third-party trackers, analytics, cookies, or
  external font libraries. No external scripts or services needed.

NOTE
